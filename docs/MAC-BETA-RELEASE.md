# Flowlist for Mac — beta

The full Flowlist workspace, a compact menu-bar timer, local tasks and sessions,
optional Google sign-in, and background account sync. Email sign-in appears only
when the beta owner has enabled and verified the email sender.

Requires macOS 14 or later. Check the asset name: `arm64` is for Apple silicon;
`x86_64` is for Intel. The current package does not include a desktop widget.

This free beta is ad-hoc signed, **not notarized by Apple**. Download the ZIP,
unzip it, and move Flowlist to Applications. Try opening it. If macOS blocks it,
use **System Settings → Privacy & Security → Open Anyway** and confirm the
app-specific exception. See [Apple's instructions](https://support.apple.com/en-us/102445).
Do not disable Gatekeeper globally. Managed Macs may prevent this exception.

On first launch, sign in or continue as a guest, follow the Guide, and choose
whether to show the menu-bar clock. Guests can work offline. Guest and account
workspaces are separate; signing in does not upload guest work.

Updates are manual: quit Flowlist and replace the app in Applications. Workspace
data is stored separately. Keep an exported backup while testing the beta.
Report bugs through the repository's Issues page without private task content.
